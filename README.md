# Misión Lloa: yaku kamachikkuna

Escape room educativo de la Unidad Educativa Franciscana San Andrés Quitumbe (Tercero de Bachillerato).
Los participantes ayudan a Yaku Camayoc y a los agricultores de papa de Lloa (Pichincha) a comparar
dos alternativas: la extensión de un canal y un servicio de traslado.

## Cómo abrirlo

Abre `index.html` con doble clic en un navegador moderno (Chrome, Edge, Firefox o Safari).
No necesita internet ni instalación. El progreso se guarda solo en el navegador.

## Cómo editarlo

- **Textos, diálogos, desafíos, respuestas y pistas:** sección `CONTENIDO EDITABLE` al inicio de `script.js`
  (`MISIONES`, `EVIDENCIAS`, `OPCIONES`, `CRITERIOS`, `DESENLACE`, `REFLEXION`).
- **Colores y estilos:** variables al inicio de `styles.css`.
- **Imágenes:** `assets/backgrounds/` (escenarios), `assets/characters/` (retratos), `assets/icons/` (insignias del mapa).
- **Audio de Inglés:** ver `assets/audio/LEEME.txt`.

## Estructura

```
index.html   styles.css   script.js
assets/  images/  characters/  backgrounds/  audio/  icons/
```
